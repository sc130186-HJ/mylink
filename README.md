# 🔗 MyLink (마이링크)

> **신예헌의 개인 프로필 & 링크 모음 웹 애플리케이션**  
> 깔끔하고 모던한 카드형 반응형 웹 디자인으로 제작된 나만의 프로필 페이지입니다.

---

## 📌 프로젝트 소개
**MyLink**는 사용자의 프로필 정보, 자기소개 및 주요 SNS/웹 링크를 한눈에 볼 수 있도록 카드 UI로 제공하는 웹 애플리케이션입니다.  
Next.js 16과 Tailwind CSS v4를 활용하여 빠르고 세련된 사용자 경험을 제공하며, 다크 모드를 지원합니다.

---

## 🛠 기술 스택 (Tech Stack)

| 분류 | 기술 |
| :--- | :--- |
| **Framework** | [Next.js](https://nextjs.org/) (App Router) |
| **Library** | [React 19](https://react.dev/) |
| **Styling** | [Tailwind CSS v4](https://tailwindcss.com/) |
| **Language** | [TypeScript](https://www.typescriptlang.org/) |
| **Linting** | ESLint |

---

## ✨ 주요 특징 (Features)
- 👤 **프로필 카드 UI**: 부드러운 그라데이션 아바타와 심플한 텍스트 구성
- 📱 **반응형 디자인**: 모바일, 태블릿, PC 모든 디바이스에 최적화
- 🌙 **다크 모드 지원**: 사용자 시스템 테마 설정에 맞춘 라이트/다크 모드 전환

---

## 🚀 실행 방법 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 페이지를 확인합니다.

### 3. 프로덕션 빌드
```bash
npm run build
npm run start
```
